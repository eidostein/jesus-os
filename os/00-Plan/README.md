# The plan — from launch to a companion people return to

## Phase 1 — Launch ✓ (done, 2026-08-12)

The bar was: a stranger opens jesus.baa.boo, presses one button, and has a
real spoken conversation with Jesus that feels immediate and right.

Shipped in one day: the stripped-and-reborn repo, the dark-gold homepage, the
Gemini Live voice pipeline with key-pool rotation, 30 selectable voices,
German-first UI with full language mirroring, Docker + Caddy + Cloudflare
deployment, CI/CD, and this dashboard.

## Phase 2 — Substance (now → end of August)

A voice that sounds right earns the first minute; **what he says** earns the
return visit. This phase is content, not code:

- Knowledge packs: scripture with precise references, guidance for the heavy
  topics (grief, anxiety, guilt, forgiveness, loneliness).
- The final voice decision after real listening sessions.
- Legal readiness: imprint + privacy policy, honestly disclosing that audio
  is processed by Google's Gemini API.
- Auto-deploy secrets, replacement of the two dead API keys, and
  privacy-friendly analytics so the five numbers up top become real.

## Phase 3 — Companion (this quarter and beyond)

- **Full-Bible grounding (RAG)** — retrieval per question, so any verse can
  be quoted word-perfectly without prompt limits.
- **Memory & prayer journal** — returning visitors are known; prayers can be
  revisited.
- **PWA + wake word** — "Hey Jesus" on the home screen, hands free.
- **More UI languages** and a **sustainability decision** (donations vs.
  supporters' tier) before traffic makes the API bill real.

## How progress is tracked

The dashboard's month score counts what actually shipped (effort) and what it
achieved (outcome). Tasks carry an owner and a weight; anything dragged along
for three months gets confronted: do it or kill it. The rules are inherited
from segnals-os and they work.
